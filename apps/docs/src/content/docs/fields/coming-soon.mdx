| Field | Status |
| --- | --- |
| `richtext` | Ships in `0.1.0-alpha`, wired to the Plate.js editor and renderer from [`@vexcms/richtext-plate`](https://platejs.org), with inline images from the media library. A dedicated `/fields/richtext/` reference page is still to be written. |

In the meantime, `richtext` behaves like every other field in `defineCollection`'s
`fields` record — `label`, `required`, `defaultValue`, `admin.condition`, and the rest
of the shared `admin` options all apply. Track the docs page on the
[roadmap](/roadmap/).
