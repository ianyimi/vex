## Commit — 2026-04-12 01:57

feat(react): add data table columns, title-field links, and edit form save

`CollectionListView` now renders a full TanStack Table. `getCollectionColumnDefs` builds column definitions by delegating to each field type's `*FieldToColumnDef` helper. All column helpers now accept `collection` and `isTitleField` props so the title cell can render as a linked edit path — `TextFieldCell` wraps the value in a `VexLink` when `isTitleField` is true, using `basePath` from the VexConfig context via the new `addLeadingSlash` utility.

`CollectionEditView` is now wired to `vexConvexApi.update` via `useMutation`, making the Save button functional. `CellComponentProps` in `@vexcms/core` gains `isTitleField: boolean` and `collection: CollectionConfig` to support this — any custom cell component will need to be updated.

`vexConvexApi.get` and `.update` drop the `collection` arg (Convex document IDs are globally unique — no collection context is needed to fetch or patch by ID). `basePath` is added to `VexConfig`/`VexConfigInput` (defaulting to `"/admin"`) and `defineConfig` is made callable without arguments to support the context default.
