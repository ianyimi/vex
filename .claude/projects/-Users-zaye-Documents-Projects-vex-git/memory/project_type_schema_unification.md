name: Type generation and schema generation need unification
description: vex.types.ts and vex.schema.ts are generated by separate code paths that can diverge — plan to unify or derive types from Convex schema directly
type: project
---

Type generation (generateVexTypes.ts) and schema generation (generateVexSchema.ts) use separate code paths. The tabs field expansion was fixed (2026-03-24) to match between both, but they can still diverge if new field types are added.

**Why:** The user discovered that `tabs` fields generated `Record<string, unknown>` in types but proper nested objects in the schema, causing wrong LSP autocomplete in access definitions. The ideal solution is to derive types directly from Convex's generated schema or unify both generators into one pass.

**How to apply:** When working on type/schema generation, remember this is a known tech debt item. If the user asks to unify them or derive types from Convex, this is the context.
