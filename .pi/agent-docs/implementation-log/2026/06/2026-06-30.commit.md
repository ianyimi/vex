
## Commit — 2026-06-30 19:45

feat(core): add VexMediaDocument type and generic TData for field cells

Add `VexMediaDocument` interface to core package so media collection views can access fields like `src`, `alt`, and `mimeType` without type casting. This mirrors the existing pattern of extending `VexDocument` with collection-specific fields (e.g., regular collections use custom field shapes).

Make `CellComponentProps` generic over both the field type and a document data type (`TData extends TDocument`). This allows cell components to know the actual row shape — critical for media documents where `row.original.src` is a known string, not an unknown field.

Update all React field components (text, number, date, checkbox, select, relationship, url, array, blocks, group) to thread `TData` through the column definition and cell component chain. Each field's `*FieldToColumnDef()` function now accepts `<TData>` and passes it to the cell component, so `row.original` is properly typed regardless of whether the collection uses regular documents or media documents.

This change enables future document types (e.g., `AuthCollectionConfig`) to follow the same pattern without modifying field components.
