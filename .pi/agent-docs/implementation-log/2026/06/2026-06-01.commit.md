## Commit — 2026-06-01 18:00

feat(core,react,www): add blocks field type with page-builder blocks

Introduces `defineBlock()` and `blocks()` in `@vexcms/core` for storing
ordered heterogeneous content sections. Each block carries a `blockType`
discriminant, stable `id`, user-editable `blockName`, and typed fields.

The field generates a discriminated `v.union()` Convex validator, a Zod
discriminated union for form validation, and named TypeScript interfaces for
every block shape. The admin UI renders blocks as accordion items inside a
searchable block-picker dialog, with add/remove controls and drag-to-reorder
via a new DnD abstraction layer over `@hello-pangea/dnd`.

On the frontend, `PageContent` dispatches blocks to typed React renderers
(hero, feature, CTA, testimonial, stats, logo cloud, FAQ, pricing, content)
instead of the legacy plain-text `content` body.

Also abstracts `@hello-pangea/dnd` into reusable `Draggable`, `Droppable`,
`DndProvider`, and `DragHandle` components, and migrates `FormArray` to the
same abstraction. Fixes a hydration mismatch in `AdminTopNav` with a
client-only mounted guard. Adds seed data for all 9 block types and
`blocks.mdx` documentation.
