## Commit — 2026-07-11 05:04

feat(theme): migrate from next-themes to custom theme system

Remove next-themes dependency and replace with custom ThemeProvider, ThemeToggle, and ThemeScript components built into @vexcms/react. This gives VexCMS full control over theme implementation while simplifying the www app setup.

The custom theme system provides SSR-safe theme initialization via ThemeScript, a headless ThemeProvider context, and a pre-built ThemeToggle component that integrates with the admin sidebar.

Also includes upload field UX improvements: file staging before opening the media picker, dropzone support in empty state, Clear button in filled state, and default tab control. Blocks field now supports multiselect in the block picker dialog with URL param-driven modal state.
