## Commit — 2026-07-12 19:56

feat(api): add pagination and bulk operations to find, search, and remove

Adds native Convex pagination support to `find` and `search` APIs via optional `paginationOpts` parameter. When provided, returns `{ page, continueCursor, isDone }` instead of plain array. Enables efficient cursor-based navigation for large datasets without loading everything upfront.

Refactors `remove` API to support bulk operations and soft delete. Replaces single `id` with `ids` array for batch deletions. Adds optional `softDelete` field name parameter — when provided, sets that field to `true` instead of permanently deleting the document.

Pagination implementation uses function overloads to preserve type safety. Without `paginationOpts`, return type is `T[]`. With `paginationOpts`, return type is `PaginationResult<T>`. Both paths preserve full populate and depth support.

Adds `CollectionTableConfig` type with defaults for admin panel data tables: page size options, default sort, bulk action toggles. Merged internal collections into main config.

Breaking changes:

- `find.queryKey(collection)` now requires full args object `find.queryKey(args)` to include pagination state
- `remove({ ctx, id })` now requires `remove({ ctx, ids: [id] })`
- `update` client args now require `collection` parameter for metadata patching

All changes covered by tests: pagination tests for find/search, bulk/soft delete tests for remove.
