feat(fields): implement select and url (renamed from imageUrl) field types

Adds `select()` and `url()` to @vexcms/core and @vexcms/react, completing
the next two fields in spec 20.

`select()` stores an array of chosen option values (`string[]`) and supports
both single and multi-select via `hasMany: boolean`. Options are configured as
`{ label, value, badgeColor? }[]` — no string shorthand. The Convex validator
generates a typed `v.array(v.union(v.literal("opt1"), ...))` scoped to the
configured options. `optionInterfaceName` is available for type generation.
The React input uses `<MultiSelect single={!fieldDef.hasMany}>` and the cell
renders badges with optional `badgeColor` styling.

`url()` is a generic URL field (renamed from `imageUrl`). The image preview
and load-validation behavior specified in the original spec were removed — the
field is now a plain text input with URL format validation via `z.url()` at
submit time. Input renders as `type="text"` to avoid browser-native URL
validation. The cell renders as `VexLink`, linking to the URL value directly
(or to the edit page for title fields), with 77-char truncation.

Deviations from spec: select defaultValue is `[]` not `""` (array contract);
no string shorthand for options; hasMany and optionInterfaceName are new.
imageUrl renamed to url throughout (function, types, components, directory,
ADMIN_FIELDS key).
