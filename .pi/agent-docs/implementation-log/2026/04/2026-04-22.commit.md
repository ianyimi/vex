## Commit — 2026-04-22 23:12

feat(fields): implement url field type and clean up agent-os content

Adds `url()` to @vexcms/core and @vexcms/react as a generic URL input
field. The field stores `v.string()` in Convex and validates URL format
via `z.url()` at submit time — not via the browser's native `type="url"`
validation. The React input is a plain text input; the cell renders as a
`VexLink` that links to the URL value (or edit page for title fields),
truncating at 77 characters.

This replaces the `imageUrl` concept from spec 20. Image preview and
load-validation behaviour were dropped in favour of a simpler generic URL
field. See spec 20 Implementation Notes for the full rationale.

VexImage.tsx adds explicit `width={64} height={64}` on both the Next.js
`<Image>` and the native `<img>` fallback, suppressing the missing-
dimensions warning. next.config.ts adds `images.domains` for Google
hostnames to enable Next.js Image optimisation for those external URLs.
`scripts/vex-dev.mjs` is a new file-watcher that restarts the CLI dev
process on source changes.

`agent-os/` content deleted — product specs, standards, and
implementation logs were migrated to `.pi/agent-docs/` in the prior
commit but the working-tree deletions were never staged. This commit
finalises that cleanup.
