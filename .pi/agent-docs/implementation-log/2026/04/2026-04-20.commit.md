feat(core): add schema config types, interfaceType on fields, and generateVexSchema

Implements Spec 21 Steps 1 and 2: schema generation config types and the
core generateVexSchema function that the CLI depends on.

Adds SchemaConfigInput / SchemaConfig to VexConfig, with defaults applied by
defineConfig (outputPath: "/convex/vex.schema.ts", typesOutputPath: "/convex/vex.types.ts").
These are the paths the CLI writes generated files to.

Adds interfaceType to every ADMIN_FIELDS entry and to BaseField / BaseFieldInput.
Each field config function (text, number, checkbox, date, select) now stamps
interfaceType onto the resolved field object. The name interfaceType was chosen
over tsType (spec) because it more precisely describes what the string is used for
— generating TypeScript interface property types in vex.types.ts.

Adds interfaceName (PascalCase slug + "Document") to CollectionConfig, set by
defineCollection via slugToPascalCase in collections/utils.ts. Storing it on the
resolved config means type generators don't recompute it, and future field-level
overrides are possible without changing the generators.

Implements collectionConfigToVexSchema in collections/schemaGen.ts (renamed from
schema.ts): builds the defineTable({...}).index().searchIndex() string for one
collection. Implements generateVexSchema in schema/generateVexSchema.ts: returns
{ update, contents } — false when no collections, true with full file content.
