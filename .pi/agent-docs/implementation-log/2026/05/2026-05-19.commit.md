## Commit — 2026-05-19 00:29

feat(core,react,docs): add array field type with FormArray component

Add a new `array()` field type to `@vexcms/core` that stores ordered lists of
any VexCMS field type. Supports nesting (multi-dimensional arrays), item count
constraints (min/max), and custom singular/plural labels.

Covers:
- `packages/core/src/fields/array/` — config, types, validator, inputSchema
- `@vexcms/react` adapter — `ArrayFieldInput`, `ArrayFieldCell`, `arrayFieldToColumnDef`
- `createFieldInput` — `mode: "array"` parameter for TanStack Form array field handling
- `FormArray` component — dynamic add/remove list with sub-field rendering
- `apps/docs/src/content/docs/fields/array.mdx` — full field type documentation

Also adds Better Auth organization/team support to `apps/www` — `anonymous()`,
`organization()` plugins with schema tables (organization, team, member,
invitation) and session tracking fields (activeOrganizationId, activeTeamId)
— needed to test the array field type with proper auth context.

JSDoc added to all exported symbols in `apps/www` source files (auth plugins,
pages queries, collections, app pages, auth client, vex config).

## Commit — 2026-05-19 21:45

feat(core,react): add group field type with recursive interface codegen

Introduces a `group()` field type to `@vexcms/core` and `@vexcms/react` that
stores a nested object of sub-fields inside a collection document. Groups can
be nested inside other groups or inside array items at any depth.

Interface generation (`interfaceGen.ts`) gains `getFieldInterfaces()`, which
does a depth-first traversal of the field tree and emits a named `export type`
declaration for every group that carries an `interfaceName` — always declaring
inner types before outer ones. Array fields now derive their `interfaceType`
from the resolved items type (e.g. `InnerGroup[]`) rather than always falling
back to `any[]`.

An `index` prop is plumbed through `InputComponentProps` and every field input
component so that `FormLabel` can render an `[N] -` prefix when a field is
rendered inside an array row. `FormArray` props are simplified by extending
`InputComponentProps` directly, removing the now-redundant `FormArrayProps`
interface. `ArrayFieldCell` also respects custom `labels.singular/plural`.

`apps/www` gains `seo` and `anotherTest` group fields on the `pages`
collection as real-world integration tests of deeply nested groups and
group-inside-array patterns. AdminLayout header is made sticky; Next.js
devIndicators moved to bottom-right.
