feat(core,react): add blocks field type for modular content layouts

Implements the blocks field — a heterogeneous ordered list of typed content blocks
for page builders, CMS-style layouts, and modular content. Each block carries a
`blockType` discriminant, stable `id`, and optional `blockName` for user-editable
labels.

Core changes:
- `defineBlock()` defines reusable block types with fields, labels, and admin icons
- `blocks()` creates fields allowing multiple block types with min/max constraints
- `blocksFieldToValidator()` generates Convex discriminated union validators
- `blocksFieldToInputSchema()` builds Zod schemas for form validation
- Interface generation emits named block types and optional union aliases

React changes:
- `FormBlocks` component renders collapsible block list with searchable Dialog picker
- `BlocksFieldInput` and `BlocksFieldCell` integrate with the adapter system
- Block items keyed by `id` (not index) for stable React reconciliation
- Sub-fields use array-bracket + dot notation paths like `"body[0].text"`

Also adds `LucideIconName` type to @vexcms/core for block picker icons without
introducing a React dependency in core.
