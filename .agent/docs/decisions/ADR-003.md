# ADR-003: anonRole fallback for public access, not a reserved `$public` matrix row

- Status: accepted
- Date: 2026-08-21

## Context

The maprios www migration requires two things from unauthenticated visitors: reading published
pages and creating contact-form submissions. All generated queries/mutations run
`hasPermission()`, which derives roles from `user[access.userRolesField]`; empty roles deny, so
anonymous callers were categorically locked out. Two designs were considered:

1. **Reserved `$public` matrix row** — a special permissions key evaluated for sessionless
   callers.
2. **`anonRole` config field** — `defineAccess({ anonRole: "user", … })`; when a caller's
   normalized roles resolve empty, `hasPermission` evaluates with `[anonRole]`.

## Decision

Option 2. The Better Auth anonymous plugin creates *real* sessions and user documents with no
roles set — a sessionless-only `$public` row would never apply to them. Keying the fallback off
"roles resolved empty" covers no-session, empty user, role-less anonymous users, and unreadable
roles values uniformly, and is auth-adapter-agnostic: the contract stays "roles come from
`userRolesField`; empty → `anonRole`".

Semantics locked in:

- **Fallback, not floor.** Any non-empty roles value (even an unknown role name) suppresses the
  fallback; anon grants never union with real roles.
- **Garbage roles values fall back.** A non-string/array roles field is treated as
  unauthenticated rather than hard-denied.
- **Enforcement stays in `hasPermission`'s role derivation** — no per-function public-visibility
  detection in the API layer; `resolveGetAuth` already passes unauthenticated callers through as
  `undefined`.

## Consequences

- Zero changes to the matrix types, wildcard resolver, or the 10+ server callsites.
- `anonRole: "user"` means every future grant to `"user"` silently extends to anonymous
  visitors; splitting to a dedicated `"anon"` role later requires no migration.
- `@vexcms/better-auth`'s `createGetAuth` must resolve `undefined` (not throw) for sessionless
  callers and return anonymous-plugin user documents as-is (verification pending in that
  package).
