feat(theme): color field and database-driven site + admin theming

**Design tokens collapse 48 → shadcn's 32.** Measured first: 13 of the 16
non-shadcn tokens in globals.css had zero component references; the other three
(14 call sites) map to `muted-foreground`, the `primary/90` opacity modifier,
and `destructive`. Matching shadcn exactly is what lets tweakcn presets map
across with no gaps. Host apps that declared the removed tokens can delete them.

**Field dispatch is exhaustive.** `adminFieldToValidator`,
`adminFieldToInputSchema` and `getCollectionColumnDefs` bind their default arms
to `never`, so registering a field type is a compile error at every site that
has not been updated; a registry-parity test pins the three React maps to
`Object.keys(ADMIN_FIELDS)` at runtime.

**The 12th field type, `color()`.** Stores a CSS colour string as `v.string()`.
`format: "hex" | "rgb" | "hsl" | "oklch"` selects what the picker writes;
validation accepts all four, so switching format never invalidates documents or
triggers a Convex migration. Alpha, plus `themeColors: true` var(--token) picks.
Conversion pivots on sRGB (`ColorValue`), so core owns `serializeColor`/
`parseColor`/`buildThemeCss` with zero new dependencies — OKLCh is hand-rolled
via Ottosson's matrices, byte-exact against Chromium and round-trip exact
across a 4096-colour lattice.

**Themes drive the whole document, admin included.** `themes.ts` carries all 32
tokens × light/dark (superseding D8's 7-field shape — a partial theme moves
`--background` without `--foreground`). `siteSettings` becomes a global with
`activeTheme`/`adminTheme`; `theme.getAdmin` falls back to `getActive`, so the
admin adopts the site palette by default and opts out via a `:root:root`
specificity ladder, never injection order. `<ThemeStyle />` covers first paint;
`<ThemeLive />` subscribes over Convex and re-skins every open tab on save with
no reload. `(frontend)/layout.tsx` is restored so the `@auth` slot lands in the
group that declares it; the dead pages-querying `convex/themes.ts` is deleted;
`seed:themes` loads four full palettes (Stark × Ember verbatim from globals.css
as the control, plus three tweakcn presets).

**Tooling and polish.** Next bumped to 16.3.3 with Turbopack's disk-cache
eviction pinned (dev sessions grew to 12GB over ~30h); users collection gains
its admin icon; UnauthorizedView copy is centered.

**Harness.** WP-C spec lands complete (8 groups, 45/45 steps, developer-
rehearsed); launch-readiness gains the WP-C DONE section with the D8 amendment;
core-field naming rule widened with convert|formats|utils.
