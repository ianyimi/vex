feat(core,react,next)!: overhaul list view and add commitTs field

**List-view overhaul.** The collection list is rebuilt as a URL-driven, server-prerendered
`CollectionListView`: search, sort, an AND/OR filter builder (`ListViewFilterBuilder`) backed by
a per-field `FilterInput` registry for every data field type, column visibility/order/pinning/
resizing (`DataTableColumnsMenu`, `useDataTableColumnResize`), page size, density, a peek panel
(`ListViewPeek`), per-row actions (`list.row.actions`) and inline bulk actions
(`list.bulkActions`). Data flows through new `useVexListQuery`/`useVexDocQuery` hooks;
`NextAdminPage` authenticates on the server, prefetches into a `serverQueryClient`, and hydrates
through `HydrationBoundaryClient` so first paint matches the client. View switches keep the
previous rows visible and prefetch the target.

**Saved list views.** `admin.view` (the default view) and `admin.views` (preset tabs) replace
`admin.table`, which is removed outright. Shared views live in a new `vex_views` table behind
`listViews`/`saveView`/`removeView` APIs, gated by `VIEW_ACTIONS` access actions and org-scoped
by `resolveViewOrganizationScope`; local views live in `localStorage` with a cookie index for
first-paint tabs. `find`/`search` push filters into indexes and cap the total count at
`countLimit` (default 10000; `search` clamps to 1023 under Convex's 1024-result ceiling),
returning `totalDocsCapped`.

**Admin cookies.** Every admin preference collapses into two `basePath`-scoped cookies,
`vex-admin` and `vex-admin:<collection>` (`adminCookie.ts` in core and react), read server-side
so density, skeleton rows, peek width and local tabs render correctly on first paint.

**commitTs() field.** A read-only, auto-indexed field type stamped with Convex's own commit
timestamp; `stampCommitTsFields` replaces `stampUpdatedAt`, the injected `updatedAt` uses it,
and values are ms at every public boundary (ns `bigint` only inside Convex). Projects,
templates and seeds are cut over.

**Fixes.** Sticky header stacking (selection/pinned body cells `z-[5]`), vertical scrollbar
starting below the header (`--vex-table-header-h`, `ScrollArea` `verticalScrollbarClassName`),
row-actions menu no longer nudged, columns-menu spacing, `DataTable` `getCanSort`, peek renders
field cells, publish uniqueness across draft pairs (`DraftPairPagination`), `commitTs` bigint
read-path conversion, view-switch dimming (`isQueryAffectingViewSwitch`), `AdminTopNav` sidebar
trigger alignment, the Publish button's spinner (`VersionPublishAction` now passes
`isPending` from `useVexMutation`; it never showed while publishing), and
`CollectionConfig`'s new optional `TFieldSlug` type parameter so TS 5.x editors stop treating
`TFields` as invariant.

**Structure refactor.** Core `collections/` splits into `savedListViews/`, `listView/` and
`query/`; React `collections/listView/` gains `toolbar/`, `create/`, `savedListViews/`,
`filters/`, `peek/`, `rowActions/`, and large components become folders with `index.tsx`.
Symbols are renamed to the `ListView`/`SavedListView`/`DataTable` vocabulary with no aliases;
`useListViewContext` becomes public; `VexConfigError` moves to core `errors.ts`;
`DENSITY_ROW_CLASS` moves to react; `ThemeScript` moves to `@vexcms/react/server`.

**Docs and examples.** New `list-views` and `admin-cookies` guides, a `testimonials` example
collection in apps/test with bulk-approve and feature row actions, the roadmap (docs, www seed,
Roadmap block) moved list views to shipped, and stale `initialData`/package-layout prose fixed.
Templates mirror the apps/test admin page/layout/auth changes; www's Roadmap block and seed copy
are marketing-only and not mirrored. Keyboard shortcuts (Step 15) are deferred to the backlog.

BREAKING CHANGE: `admin.table` is removed — move its keys to `admin.view` / `admin.views`.
List-view exports are renamed without aliases (e.g. `composeViewWhere` →
`composeSavedListViewWhere`, `parseListParams` → `parseListViewUrlState`, `BulkDeleteModal` →
`DataTableBulkDeleteModal`, `CreateDocumentModal` → `ListViewCreateDocumentModal`,
`ListViewTabs` → `SavedListViewTabs`, `ListPeek` → `ListViewPeek`); `CollectionListViewProps`
loses `initialData`/`initialQueryError`/`initialViews`/`initialPeekDoc`; `ThemeScript` imports
from `@vexcms/react/server`; `updatedAt` is a `commitTs()` field. See `.changeset/` for the
full list.
