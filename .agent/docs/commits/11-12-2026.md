feat!: alpha.38 replay fixes, zero-cast typed APIs and public admin gate

**Zero-cast consumer types (P-030).** Replaying alpha.38 on the four golden
examples surfaced every `as never`/`as unknown as` a consumer still needed;
each library gap is fixed and pinned by a `*.typecheck.ts`. `@vexcms/core`
gains `vexFindQuery`/`vexGetQuery`/`vexSearchQuery` (typed direct network calls
for any `{ query(ref, args) }` client; `@vexcms/react/client` now delegates to
the same builders) and exports `isHiddenDocument`, replacing five private
`value: unknown` copies. `buildThemeCss` accepts a closed generated document,
`AccessIndexedFieldWithValue` intersects `AccessIndexedFieldFor`, the
`useLivePreviewQuery`/`useLivePreviewDocumentQuery` `TData` override no longer
extends the raw document (populated query results type without casts), and
`defineMediaCollection`'s `storageId` is `Id<"_storage">`. A generic
`VexApiAuth` was tried and reverted (breaks dynamic `auth.user.<field>` reads,
TS2589); the last cast is tracked in the backlog.

**Admin gate on public pages.** `useCanAccessAdminPanel()` always returned
`false` outside `/admin` because `VexAuthContext` is seeded only there. It now
falls back to a new `VexSessionAdapterProvider` around the app's client session
and returns `{ canAccess, isPending }` so headers reserve the link slot.
Mounted at the root of apps/test, apps/www and both templates.

**Auth transition races.** `useNextAuthTransitionRefresh` no longer refreshes on
the bootstrap `null → id` transition (sidebar re-flash on every load), and
`beginTransition(null, { skipRefresh: true })` lets same-tab sign-out skip the
soft refresh that raced its hard navigation.

**Admin UI fixes.** `ThemeProvider`'s mounted flag flips in a passive effect so
`ThemeToggle` enables on streamed pages; upload/relationship pending rows reuse
the settled row box (no shift); read-only filled values mute to `opacity-50`;
the relationship picker awaits `closePicker()` before `handleChange` (sibling
reopen race); saved-view hidden filters split leaf-by-leaf via
`splitWhereByReadability`/`isFieldReadable`, showing readable conditions as
locked chips.

**Apps and templates.** App-level Convex functions use the bound vex API instead
of raw `ctx.db` on registered collections; `base-nextjs` gains
`getUserOrgForVexApi` and both templates pass it to every
`authPromise`/`getAuth` (fresh scaffolds failed their first typecheck);
`scaffold-smoke.mjs` asserts that bridge. Geist loads via `next/font/local`
(vercel/next.js#99114 wedged Turbopack dev). `template-diff.mjs` drift left
unmirrored is marketing copy and pre-existing app-only files.

**Docs and planning.** `guides/access-control.mdx` documents the public admin
gate and `isHiddenDocument`; `guides/live-preview.mdx` sign-out uses
`skipRefresh`. P-030 recorded; replay results, cast audit and backlog items
(typed auth user, blur placeholders, muted read-only images) added.

BREAKING CHANGE: `useCanAccessAdminPanel()` returns `{ canAccess, isPending }`
instead of `boolean`; mount `VexSessionAdapterProvider` at the app root for
public pages. `toClientSavedListViewConfig` requires an `isFieldReadable`
predicate. `buildThemeCss`'s `theme` is typed `object`; the live-preview hooks'
`TData` is unconstrained; media `storageId` is `Id<"_storage">`.
