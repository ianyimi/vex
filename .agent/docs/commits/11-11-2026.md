feat!: cross-page live preview and golden use-case fixes for alpha.38

**Live preview across pages.** The preview gate no longer depends on
`?vexLivePreview=1` being on every URL: once it opens, the provider names its
window `LIVE_PREVIEW_WINDOW_NAME` (`@vexcms/core`) and the gate accepts that
name, so links, back/forward and reloads inside the panel or pop-out keep the
overlay. A freshly loaded page posts a ready message that every open edit view
answers, replacing the per-document mount handshake. New
`useIsLivePreviewActive()` (`@vexcms/react`) exposes the same gate and replaces
each app's `useSitePreviewMode` copy. The `base-nextjs` template (and `--bare`)
now ships `<LivePreviewProvider>`, `/api/vex/live-preview` and the proxy
hand-off, inert until a collection sets `admin.livePreview.url`.

**Expired preview sessions.** New `disableLivePreview()` on
`@vexcms/next/livePreview/client` (split from the server-only route entry so
client sign-out buttons do not pull in `next/headers`) clears the Draft Mode
and preview cookies on every sign-out path. `admin.livePreview.expiredSessions:
"deny"` makes `proxy.ts` bounce an unauthenticated request carrying either
cookie through the disable route. `getBySlugPreview` drops its explicit
`readDrafts` access override, so anonymous callers get the published row
instead of `[]`.

**Populate.** A populated relationship/upload target is checked against its own
collection's `read` rule and field-permission map; an unreadable target becomes
a `HiddenDocument` placeholder, rendered in the admin as `AccessDeniedItemRow`
/ `AccessDeniedChip`. `populate`/`depth` now reach fields nested in `blocks()`,
`array()` and `group()`, driven by the generated `CollectionsPopulateMap`.
`getGlobal` narrows populated relationships to the target document type, and
generated document interfaces extend the closed `VexDocumentShape` so
`Omit`/`Pick` keep literal unions.

**Validation and versions.** `validate()` gains `dependsOn` to re-run a
cross-field validator on partial writes. A first-ever `publish` authorizes
owner rules against the draft row instead of an empty published row.

**Auth flow.** Sign-out hard-navigates to the new client-safe
`config.auth.signOut.redirectTo` (default `"/"`) instead of re-rendering the
admin shell signed out; `AuthViewProvider` sign-in hard-navigates too, ending a
router.refresh/push race that silently left users on the sign-in page.
`useNextAuthTransitionRefresh` refreshes the admin layout when identity changes
in another tab. `betterAuthAdapter` keeps `roles` admin-editable, and
`convex/auth/api.ts`'s self-lookups pass `access: { bypass: true }` so the
admin stays reachable on a fresh scaffold.

**Admin UI.** Top bar shows the caller via the new `UserDisplay` and publishes
`--vex-topbar-h` for the peek panel's offset; sidebar skeleton renders
per-section counts remembered in the `vex-admin` cookie (`sidebarCounts`) plus
a disabled `ThemeToggle`, with a `mounted`-gated icon fixing a hydration
mismatch. Peek skeleton mirrors the settled panel; the bulk-selection group
renders last and "Select all N loaded" is gone; media list no longer overflows
the viewport; `row()` frees slots of condition-hidden children; Save routes
through `form.handleSubmit()` so failed saves scroll to the first (nested)
error; masked numbers keep the caret and left-align; `renderDefault` is stable.

**CLI and release.** `vex dev` forwards unknown flags to `convex dev`
(`--start 'next dev'` included). The release workflow runs network-bound tests
with `VEX_NETWORK_TESTS=1`.

**Templates.** `apps/test` and `apps/www` changes mirrored into `base-nextjs`
and `marketing-site` (auth api bypass, sign-out wiring, preview hook cutover,
proxy, layout, `pages.ts`). The remaining `template-diff.mjs` drift is
marketing copy and pre-existing app-only files, deliberately not mirrored.

**Planning.** alpha.38 replay and live-deployment runbooks for the four golden
examples, final-sprint ordering for v0.1.0, coordination board LP rows, and
four live-preview follow-ups in the backlog. The `auth-file-roles` naming rule
admits colocated `.test` files.

BREAKING CHANGE: populated targets the caller cannot read are now
`HiddenDocument` placeholders — grant `read` on the target collection where the
value should stay visible. `FrameworkAuthAdapter.signOut` must hard-navigate to
`config.auth.signOut.redirectTo`, and `config.auth` is always present (test
`config.auth.adapter` instead). Generated documents are no longer assignable to
`VexDocument`/`TDocument` without a cast; run `vex generate`. Apps must replace
`useSitePreviewMode` with `useIsLivePreviewActive`.
