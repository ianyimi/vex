feat(create-vexcms): support npm, pnpm, yarn, bun and deno

**Scaffolder.** A new `helpers/packageManager.ts` owns every per-manager command spelling
(`resolvePackageManager`, `packageManagerField`, `runScriptCommand`, `execBinCommand`,
`addPackagesCommand`, `rewriteCommands`). The manager comes from the invoking command's
`npm_config_user_agent`, or from Deno's runtime, and `--use-npm|pnpm|yarn|bun|deno` overrides
it. `VexFrameworkInstaller.configurePackageManager` writes `packageManager` only when the
manager reported an exact version (never `npm@?`, never for Deno). It also writes `vex:update`
and the scaffold README in that manager's syntax, and puts the version pins where each manager
reads them: `pnpm-workspace.yaml` for pnpm 11+, `resolutions` for yarn, `overrides` for the
rest. Yarn gets a `.yarnrc.yml` (node-modules linker, `@vexcms/*` exempt from the 1-day age
gate) and Deno a `deno.json` with the same exemption. The CLI prints the next steps at the end.
On the published alpha.41 only pnpm 10 and bun produced a working project.

**Templates.** base-nextjs now declares better-auth-ui's peers and `better-call` 1.4.5
directly, and pins the `@typescript-eslint/*` family, so every manager resolves the same tree.
marketing-site `src/lib/metadata.ts` stops casting to `Record<string, unknown>[]`, which broke
`next build` after `vex dev` regenerated `vex.types.ts`.

**CLI.** `convexProcess` runs `deno x convex` for a `deno.lock` project, and falls back to
`npx` with a warning when `deno` isn't installed.

**Docs.** `starlight-package-managers` 0.13.1 is wrapped in `PmCommand.astro`. `PmTabs.astro`
is used where the plugin can't express Deno `create`, a tagged `yarn create`, or a
per-manager `--cmd`. Both share one syncKey across six guides. The root and 8 package READMEs
get one `<details>` block per manager; the better-auth/cli/file-storage-convex install lines
now say `@alpha`.

**Hero install command.** A fixed-width package-manager select is joined to the command
strip. Every manager's command is reserved in one grid cell, so the strip never resizes, and
the copy icon is now visible on the code surface. Same component in apps/www, apps/test and
the marketing template; apps/www gets hydration and select tests. www's `metadata.ts`
differs from the template by design and was not synced.

**CI.** `scripts/verify-scaffold.mjs --pm <manager>`; the new
`scaffold-package-managers.yml` matrix (Deno and yarn 1 allowed to fail) runs on
`workflow_dispatch`, and `release.yml` must pass it before releasing.

Changesets: create-vexcms-package-managers, cli-deno-convex-runner (patch).
Also carries other sessions' `.agent` bookkeeping (final-sprint, state).
