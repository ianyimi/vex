feat(fields): add bytes, keyValue, variant and field storage overrides

**New field types (FT).** `bytes()` (`v.bytes()`, File + Hex tabs, `maxSize`
default `BYTES_FIELD_DEFAULT_MAX_SIZE`), `keyValue()` (`v.record`, string or
`keys.collection` id keys) and `variant()` (discriminated object union, or a
primitive union with no discriminator) cover the Convex validator shapes VexCMS
had no field for, so projects using them can migrate. Each ships a core field
module (validator, input schema, interface gen, depth/populate, duplicate and
array/block id backfill through the shared `walkVariantValue`), a React
input/cell/display, a docs page and telemetry. An optional `variant()` starts
empty with a None option; an empty `variants` list throws `VexConfigError`.
keyValue labels every row and flags an empty key per row, blocking the save.

**Storage overrides and `nullable`.** Every data field takes `nullable`
(`v.nullable(...)`, generated `| null`, a null toggle for containers and
checkbox). `schema.validator` picks the stored validator: `number` "int64"
(native bigint), `select` "literal" | "string", `relationship`/`upload`
"id" | "string" (single-value only). Better Auth `references` columns become
string-stored relationships. `null` in `data` unsets an optional non-nullable
field (`prepareEdit`, carried through `publishShared`). Display and clipboard
are bigint/ArrayBuffer-safe (`stringifyConvexValue` with a per-call bigint
sentinel nonce); Next serializes bigint across RSC natively, so no hydration
shim is needed.

**Admin fixes.** Every `createContext` in `@vexcms/react` goes through the new
exported `globalSingleton` (`Symbol.for` on `globalThis`), and `@vexcms/next`'s
`VexAdminAuthAdapterContext` uses it too: Turbopack production builds
duplicated `VexConfigContext` and 500'd `/admin`. `verify-scaffold.mjs` now
fails on that class of error. Sign-out full-reloads the current page instead
of navigating to `auth.signOut.redirectTo`, so the server guards decide what a
signed-out visitor sees; `redirectTo` stays on `defineConfig()` for custom
wrappers. `ScrollRestoreScript` restores a reloaded edit view's scroll
position. Relationship/upload picker `isOpen` is local state, so sibling
pickers no longer reset each other. Test kit: `extraFieldFixtures` adds int64,
scalar select and scalar relationship fixtures, and `FieldFixture.cellTruncates`.

**Apps and templates.** `apps/test` gains the `storageShapes` dogfood
collection. The sign-out reload and `ScrollRestoreScript` are mirrored to
`apps/www` and the `base-nextjs` template (marketing-site layout and
`SessionButton` too); the dogfood collection is test-only and not mirrored.

**Agent skill (SK).** `skills/vexcms-project-init` is the first installable
Agent Skill (scaffold, Convex cloud dev deployment, env, first admin), with
the `/guides/agent-skills/` docs guide, `agent-setup.md` and an llms.txt
details line.

**Public presence (PP).** The private pitch deck, monetization draft and
private inventory leave the repo (the 2026-11-17 cleanup), and the product,
research and spec docs drop prices and paid-tier names; `.agent/` stays
tracked. Board, launch plan and spec ticks are updated.
