## Naming Rule Summary

| Scope | Rule ID | Convention |
|---|---|---|
| `packages/react/src/components/**/*.tsx, !packages/react/src/components/ui/**, !packages/react/src/components/fields/**, packages/next/src/**/*.tsx` | react-components-pascal | React component files are PascalCase named after their default export. |
| `packages/react/src/components/ui/**` | shadcn-ui-kebab | shadcn-generated primitives keep their kebab-case names (button.tsx, alert-dialog.tsx); hand-written additions in ui/ may be PascalCase (ThemeProvider.tsx, data-table/DataTable.tsx). |
| `packages/react/src/hooks/**` | hooks-camel-use | Hook files are camelCase named after the exported hook. shadcn-generated hooks (use-mobile.ts) keep kebab-case. |
| `packages/core/src/fields/*/**` | core-field-module | Each core field dir (lowercase widget name) contains config.ts, types.ts, validator.ts, inputSchema.ts, with colocated .test.ts files. |
| `packages/react/src/components/fields/*/**` | react-field-module | Each react field dir mirrors the core field name and contains Input.tsx, Cell.tsx, columnDef.tsx (+ index.ts barrel). |
| `packages/*/src/**/*.test.*` | tests-colocated | Tests are colocated next to the unit under test with a .test.ts(x) suffix — no __tests__ dirs, no .spec suffix. |
| `packages/core/src/**, packages/cli/src/**` | non-component-camel | Non-component TypeScript files are camelCase (or established lowercase names like constants.ts). |
| `packages/core/src/api/*/**` | api-operation-split | Core API dirs split client/server implementations. A single-operation dir is named for the operation and holds client.ts / server.ts; a grouped dir (globals, versions) is named for the resource and prefixes each file with its operation. |
| `packages/cli/src/commands/**` | cli-command-verbs | CLI command files are camelCase verbs naming the action. |
| `apps/www/convex/*.ts, apps/www/convex/auth/**, apps/www/convex/vex/**` | convex-resource-files | Convex function files are camelCase resource/action nouns. |
| `packages/react/src/**/*Context.*, apps/www/src/**/*Context.*` | react-context-suffix | React Context definition files are PascalCase with a Context suffix; a context with a companion hook lives instead as one hooks/useXxx.ts file. |
| `apps/www/src/auth/**` | auth-file-roles | Host-app auth files use fixed role names separating client/server/util/config concerns. RBAC adds `access` (the `defineAccess` matrix), `hasPermission` (the app-side check wrapper), and `plugins` (the better-auth plugin list). A role may carry a `<role>.typecheck.ts` sibling — a pure compile-time assertion file (P-008) that `tsc` enforces; it pins the role's generated/registry-derived types (e.g. `access.typecheck.ts` pins slug-aware action unions). |
