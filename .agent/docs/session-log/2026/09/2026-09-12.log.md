### What was built

- **`group()`'s collapse option renamed.** The top-level `defaultOpen` is gone; groups now
  take `admin.defaultCollapsed`, mirroring `blocks()`' option of the same name and Payload's.
  Polarity is the INVERSE of what it replaced. Call sites migrated in `apps/test`
  (`collections/pages.ts`) and `apps/www` (`collections/themes.ts`).
- **Read access no longer disables form navigation.** `FormGroup` and `FormBlocks` stopped
  passing `readOnly` to `AccordionItem`'s own `disabled` prop, so a caller with read but no
  write access can expand a `group`, `array` or `blocks` field to SEE its values. Add/remove,
  drag handles, the `blockName` input and every sub-field stay gated.
- **Accordion no longer flashes on load.** `AccordionContent` animates with a CSS transition
  on the inner wrapper's height instead of the `animate-accordion-*` keyframes.
- **Field-permission docs brought in line with what actually shipped** —
  `guides/access-control.mdx` (largely rewritten), a new `## Access control` section in
  `guides/globals.mdx`, field-stripping notes in `guides/local-api.mdx`, and the three
  package READMEs.
- **Regression tests** for the navigation rule: 15 new cases in `testing/nestedFieldContainer.ts`
  (group/array/blocks × 5 child types), so every field Input contract asserts it.

### Decisions made

- **`defaultCollapsed` defaults to `false`** (expanded), matching `blocks/config.ts`. An
  intermediate state had it `true`; the developer settled on `false` so the rename is a pure
  API change rather than also a behaviour change.
- **Disclosure triggers are identified by `data-slot="accordion-trigger"`, not
  `aria-expanded`.** The first attempt used `aria-expanded` and wrongly matched a nested
  `select`'s combobox — an editing control that must stay disabled. Added the missing
  `data-slot` to `FormBlocks`' `AccordionPrimitive.Trigger` for parity with the `ui/accordion`
  wrapper rather than matching on a Tailwind class.
- **The cascade test now SKIPS the disclosure trigger** instead of asserting every control is
  inert. The old assertion encoded the bug it was meant to guard.
- **Dropped the `animate-accordion-*` keyframes rather than trying to suppress them.**
  `tw-animate-css` animates toward `--radix/bits/reka/kb-accordion-content-height`; Base UI
  publishes `--accordion-panel-height`, so the animation always ran from `height: 0` to a
  bogus end value. Two attempts to withhold the class (a post-mount flag, then an
  `initiallyOpen` prop) both failed, because applying an `animation-*` class to an element
  already matching `data-open` starts the animation at that moment — the collapse just moved
  later in the timeline. A transition interpolates only on a real height change, so
  mount-open is simply open.
- **`keepMounted` was rejected** as a way to keep the open/close transition: the group
  contract asserts collapsed content is fully unmounted.

### Problems hit

- **Read-only forms could not be navigated.** Traced to `10d3809`
  ("fix(fields): enforce required and fix a11y across every field type"), which deliberately
  made accordion triggers inert under `readOnly` — pre-existing, not from the field-permission
  work, which only changed what `readOnly` evaluates to. Fixed at the two `AccordionItem`
  sites.
- **The rename shipped with inverted JSDoc.** The old `defaultOpen` prose was copied verbatim
  onto the flipped flag, so "Defaults to `true`. Set `false` for secondary or rarely-edited
  groups" described the opposite of the behaviour. Rewritten in both interfaces, in the
  defaults block, and in the `@example`.
- **A stale test blocked the workspace suite.** `group/Input.test.tsx` asserted "starts
  collapsed when `admin.defaultCollapsed: false`". Inverted to `true`.
- **Four rounds on the load flash**, resolved only by measuring rather than reasoning: a
  `requestAnimationFrame` timeline showed the panel at `height: 0` for ~70ms while its child
  was already 2316px, with `--accordion-panel-height` still `auto` — which ruled out the
  height var and the inner div and pointed at the keyframes.
