### Decisions made

- **Dropped `aria-required` from every `role="group"` container wrapper** (array/group/
  blocks), deviating from the spec's literal code sample. axe flags `aria-required` as not
  ARIA-allowed on `role="group"` — required-ness is conveyed by the group's own visible
  asterisk instead, already covered by an existing shared-contract test.
- **Relationship trigger takes `role="combobox"`**, not the spec's plain `<Button>`. Needed
  once `id={name}` was added (for the shared contract's `getControl` byId lookup) — a native
  `<label for>` pointing at a `<button>` overrides the button's own content as its accessible
  name in this environment, so the trigger's dynamic "Alpha"/"Select Document…" text was
  getting clobbered to the static field label. `role="combobox"` matches the pattern already
  used by `date`/`select`'s own triggers.
- **Base UI Popover/Dialog exit-animation timing**: several tests asserted
  `queryByRole(...).not.toBeInTheDocument()` synchronously right after a closing click, racing
  Base UI's CSS-driven unmount (`data-closed:animate-out`). Wrapped in `waitFor` rather than
  touching product code — a harness timing gap, not a component defect (relationship's chip
  removal, single-select close/reopen/clear; blocks' picker dialog add/Escape-close).
- **Rebuilt `packages/core`/`react`/`next` before Step 13's `apps/test` verification.**
