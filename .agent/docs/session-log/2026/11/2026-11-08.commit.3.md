feat(react,core,next,www,test,create-vexcms)!: tree-shakeable packages, /admin entry, lazy icons

Public pages loaded about 3.2 MB of JavaScript, most of it admin panel: TanStack
Table, dnd, every field component, all 1703 lucide icons and the auth UI. CI
Lighthouse TBT was 277–570 ms against a 200 ms budget. Any consumer importing one
hook from `@vexcms/react` paid for the whole package.

**Per-module dist (react, core).** `scripts/preserveModulesPlugin.mjs` makes tsup
emit one dist file per source module instead of a shared `chunk-*.js`, so bundlers
tree-shake per module. The react root barrel no longer carries `"use client"`. Each
client module declares its own, enforced by `src/clientDirective.test.ts`. `sideEffects`
is `["./src/adapter.ts", "./dist/adapter.js"]`. The `./form` export now points at
`dist/forms/*` (its types path never existed). ADR-017 supersedes ADR-009.

**Root vs `@vexcms/react/admin`.** A server component importing a barrel ships every
`"use client"` module the barrel reaches, so panel internals moved behind
`src/adminEntry.ts`:
- `reactAdapter` and the field `*Admin`/`*Cell` components
- slots and the document-edit runtime
- admin layout/views and collection/media/global views
- list-view context, `LivePreviewPanel`, the modal surface, `useVexForm`
- data-table, dnd, sidebar and resizable
- new exports: `VersionHistoryDropdown` and `AdminFieldBinding`

`useAppForm`/`AppForm` live at `@vexcms/react/form`. `ReactHKT`/`ReactAdapter` types
stay importable from the root. `@vexcms/next` imports the moved views from `/admin`.

**Icons.** `Icon` loads icons on demand through `lucide-react/dynamic.mjs` (lucide
0.577.0 has no exports map), with a same-size placeholder, everywhere including the
admin. `isIconName` guards untyped names. `resolveIconNodes` (`@vexcms/react/server`)
plus `IconNodeProvider` render CMS icons synchronously from the server HTML. Pages and
the site layout resolve their documents' icons, so first paint makes no icon requests.
The Features, HowItWorks, Footer and Split blocks use `Icon` instead of `icons[name]`.
`SessionButton` uses static icons.

**Auth UI.** `AuthUIProvider` mounts only in `src/auth/AuthViewProvider.tsx` around
`AuthView` (www, test, base-nextjs). The create-vexcms installer writes the OAuth and
credentials options there.

**Hero.** Only the heading animates. The badge, subheading, CTAs and install command
render at first paint; the CTA's delayed reveal was the LCP element.

**Gates.**
- `scripts/check-import-cost.mjs` (CI): esbuild consumer fixtures against `dist`.
  `cn` costs 26.5 KB (was 2.3 MB), `useLivePreviewQuery` 14.5 KB, and the root's full
  reach has no admin module.
- `scripts/check-site-bundle.mjs` (CI, apps/test): Next's analyzer, per-route budgets
  and a deny list. `/` is about 1.78 MB (was 3.35 MB). It fails when a route is absent
  from the analysis.
- `scripts/export-names.mjs` reads exports statically and tracks every react entry.
- Local Lighthouse: performance 1.0 on `/`, `/features` and `/auth/sign-in`
  (TBT 8–77 ms, CLS 0).

**Fixes.** `dropdown-menu.test.tsx` waits for Base UI's rAF focus before typing;
`verify-scaffold.mjs --negative` awaits `runTemplate`. Templates mirror every app
change. Docs gain a "What ships to your pages" section and corrected `/admin` imports.

BREAKING CHANGE: panel internals moved from `@vexcms/react` to `@vexcms/react/admin`,
and `useAppForm`/`AppForm` to `@vexcms/react/form`. The migration table is in
`.changeset/react-admin-entry.md`. `AdminIcon` never shipped; use `Icon`.
