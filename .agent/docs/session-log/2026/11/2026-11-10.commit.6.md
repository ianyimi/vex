release: 0.1.0-alpha.37 — vex deploy passthrough, access auto-index, scoped themes, scaffold hygiene

`master` 0.1.0-alpha.36 → 0.1.0-alpha.37, one commit on `dev`. The version bump is already committed (versioned locally), so `master` receives no pending changesets and the Release workflow publishes on merge — no "chore: version packages" PR this time.

**Deploying.** `vex deploy` forwards every unknown flag to the final `convex deploy` (`--cmd`, `--preview-create`, …), honors `--cwd`, runs the custom build once instead of on every interim schema push, and no longer times out after 120s. Scaffolds ship a `vex:deploy` script; the new deployment guide replaces the README's `npx convex deploy` recipe.

**Access and schema.** Index-backed access checks (`indexedOwnerCheck`, `ownerPredicateCheck`, `indexedEqCheck`) now see a relationship's automatic `by_<field>` index. `convex/schema.ts` imports the `user` table from the generated schema, so user-collection fields reach `Doc<"user">` with no second edit. Raw server calls now require `config`.

**Theming, live preview, testing.** `buildThemeCss({ scope: { selector } })` scopes a palette to one region; live-preview query hooks infer without an `as never` cast; `runVexReactSuite` accepts real `*FieldAdmin` components.

**Scaffolder.** Env validation skips the Convex runtime (fixes pushes failing with "Invalid environment variables"); secrets stay out of `.env.example`; `.env.example` is no longer gitignored; `packageManager`, npm/yarn overrides and `--bare` scripts are correct.

**Changesets by package**
- `@vexcms/core`: access-relationship-auto-index, react-theme-region-scope-and-live-preview-inference, schema-user-table-single-source, server-api-config-required
- `@vexcms/react`: react-theme-region-scope-and-live-preview-inference
- `@vexcms/cli`: cli-deploy-flag-passthrough
- `create-vexcms`: create-vexcms-deploy-script, scaffold-hygiene-and-convex-safe-env, schema-user-table-single-source
- `@vexcms/next`, `@vexcms/better-auth`, `@vexcms/file-storage-convex`, `@vexcms/richtext-plate`: fixed-group bump only

BREAKING CHANGE: raw `@vexcms/core/server` calls (`find`, `get`, `search`, `publishedSlugs`) must pass `config`; calls through `vexServerApi()` are unaffected.
