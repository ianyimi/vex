fix(deps): declare zod peer for @hookform/resolvers

www's Vercel build failed with "Can't resolve 'zod/v4/core'" inside
`@hookform/resolvers` 5.4.0. That package comes in through
`@daveyplate/better-auth-ui`'s forms, not our code, and imports `zod` without
declaring it, so it resolved only when pnpm happened to hoist a compatible
`zod` to `node_modules/.pnpm/node_modules`. A `pnpm.packageExtensions` entry
in the root and the base-nextjs template gives it a `zod >=3.25.0` peer, so
pnpm links the app's `zod` (4.6.7) straight into its `node_modules`.
Changeset `hookform-resolvers-zod-peer` for create-vexcms.
