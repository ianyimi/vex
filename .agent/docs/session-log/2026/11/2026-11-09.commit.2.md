ci(release): lint after building packages

The Release run for PR #75 failed at Lint:
- apps/www `src/vex.config.ts:27`: `no-unsafe-assignment` and `no-unsafe-call`
  on `plateEditor()`.

The app lint added to release.yml for D6 is type-aware. It ran before
"Build Packages", but `@vexcms/richtext-plate` has no `source` export
condition, so its types exist only in `dist/` once the package is built. On a
fresh runner `plateEditor()` resolved to an `error` type. ci.yml already lints
after building, which is why the PR's CI run passed.

The Lint step now runs after "Build Packages" and before "Typecheck Packages",
matching ci.yml.

Reproduced locally: with `packages/richtext-plate/dist` moved aside, eslint on
apps/www `src/vex.config.ts` reports the same two errors; with it restored,
there are none.
