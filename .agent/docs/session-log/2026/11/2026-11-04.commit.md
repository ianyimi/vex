feat(core,test,docs): finish richtext, field input pass, hooks checks

**Richtext field closeout.** The `apps/test` dogfood (root `editor: plateEditor()`,
`posts.body` as `richtext()` with inline images from `images`, `/posts/[slug]` rendering
through `RichText`) is confirmed end to end. `scripts/check-packed-manifests.mjs` gains a
`--richtext` consumer probe: it packs core, react and richtext-plate, installs the tarballs
into a throwaway package and typechecks `richtext()`, `plateEditor()` and `RichText` against
the published declarations. `--richtext-negative` strips core's `richtext` export and must
fail, which proves the probe can detect a missing export. The core and richtext-plate READMEs
drop their "richtext not shipped yet" framing, and `fields/coming-soon.mdx` is removed because
every field it listed has shipped.

**Field input pass dogfood.** `apps/test` `pages` now exercises `tabs()`/`row()`/`collapsible()`,
the `email`/`textarea`/`json` fields, a masked phone field with a per-field `Input` override
(`renderDefault` wrapper) and a `field.beforeInput` contribution, and a `ui()` word count.
`vex.config.ts` adds `fields.inputMasks.number`, a root `fields.text.Input` override
(`TrimOnBlurTextInput`) and a root `blocks.itemActions` hide for `vex.block.duplicate`. The CTA
block switches to a `linkType` select with conditional `internalPage`/`externalUrl` fields,
resolved by `resolveHref`, and the seed CTA actions migrate to that shape. Docs `roadmap.md`,
the www Roadmap block and both seeds now list the pass as shipped.

**Root action hides now work.** `defineConfig()` used to pre-resolve
`admin.components.blocks.itemActions`/`headerActions` and `array.itemActions` through
`resolveComponentContributions`, which drops hide-only `{ id, hidden: true }` entries because
there are no built-ins to match at config time. `BlockActionsMenu` and the array `Field` then
re-merged against the built-ins without them, so a project-wide hide did nothing. These lists
now pass through raw, like `edit.*`, and are resolved per placement at render time.

**Page-size picker includes a custom `pageSize`.** With `pageSizeOptions` unset,
`defineCollection()` offers `[10, 25, 50, 100]` plus the view's `pageSize`, de-duplicated and
sorted (`pageSize: 20` gives 10/20/25/50/100), and saved views inherit that list. Before, a
custom page size could not be selected in the picker. Explicit options, including `[]` (which
hides the picker), are unchanged. Documented in the pagination guide.

**Lifecycle hooks follow-ups.** New `scripts/verify-hooks-wiring.mjs` (exports
`verifyHooksWiring`) fails when an app's `convex/vex.ts` stops calling `createVexMutations`, or
when `convex/vex/globals.ts`/`media.ts` import `mutation` straight from `_generated/server` and
bypass the trigger-wrapped `vexMutation`. `verify-scaffold.mjs` runs the same check on each
freshly scaffolded template. New `guides/lifecycle-hooks.mdx` covers the four hooks, the two
validation tiers (generated Zod on client and server vs. server-only `validate()`), coverage
limits, BFS trigger recursion and live-preview behavior. The roadmap and core README now link
it.

The launch plan marks D, G and F delivered and ticks the code-closeout item.
