feat(react,core,next)!: overhaul edit view with slots and actions menu

**Edit-view extension points (spec H).** Core gains `SLOT_IDS.edit` — `edit.header.actions`, `edit.header.before`/`after`, `edit.actionsMenu`, `edit.beforeFields`/`afterFields`, `edit.sidebar.before`/`after` — plus `header.overrides`, `resolveEditSlot`, `EditSlotProps`, and `BUILTIN_CONTRIBUTION_IDS.edit` (`vex.save`, `vex.publish`, `vex.unpublish`, `vex.delete`, `vex.cancel`, `vex.duplicate`, `vex.revalidate`, `vex.versionHistory`, `vex.livePreview`). `SlotAccessContext` gains `resource` so access callbacks know the collection/global. `CollectionEditView` and `GlobalEditView` now render every built-in as an ordinary contribution through `DocumentEditSlotOutlet`, so projects can hide, reorder, or replace them; `useVexDocument` exposes the current document to contributed components. `DraftToolbar` is gone — its buttons are `VersionPublishAction`/`VersionUnpublishAction`/`DocumentSaveAction`.

**Header layout and the ⋯ menu.** Developer review settled the order ⋯, Preview, Save Draft, Publish|Unpublish (one min-width spot, so swapping never shifts the row), Cancel, Delete (trash icon, confirm dismisses on outside click). Rare actions live in `DocumentEditActionsMenu` — History (`VersionHistoryMenuItem` → `VersionHistoryPanel`), Revalidate (`RevalidateMenuItem`), Duplicate. `EditActionsMenuItem` lets project items match the built-ins, and `useEditActionsMenuDialog` hosts dialogs outside the dropdown so they survive it closing. `useHeaderActionsCollapse` measures the row and collapses progressively: title ellipsis first, then Delete, Preview, and finally Cancel into the menu. A short-lived `@formkit/auto-animate` experiment was removed entirely.

**Duplicate document.** Core `cloneDocumentForDuplicate` strips framework fields (`_id`, `_creationTime`, `updatedAt`, `vex_*` version fields) and regenerates every array/block item id — unique values like `slug` copy as-is and conflicts land in the fallback form; `create` accepts a `status` arg (validated by the new `VERSION_STATUS_SCHEMA`/`VERSION_STATUS_SCHEMA_SOURCE`) so a versioned duplicate lands as a draft. `useDuplicateCollectionDocument` tries a silent create (`useVexMutation` `errorToast: false`) and falls back to a prefilled all-fields create form when validation fails.

**Unsaved-changes guard.** `useUnsavedChangesGuard` + `UnsavedChangesDialog` block in-app links and back/forward on a dirty form; `useVexNavigate` routes through the framework adapter. `@vexcms/next` adds a navigation blocker (`navigation/`) using a history sentinel pushed whenever the guard arms, Leave = `go(-2)`, and no history traversal on unmount — the spec draft's mount-only sentinel never guarded Back. `DocumentEditSlotOutlet` no longer builds component types during render, which had remounted built-ins on every Convex update.

**Admin routing.** Collection URLs move to `/admin/collections/<slug>[/<id>]`; `adminHref`, `NextAdminPage`, `NextAdminLayoutClient`, and `AdminTopNav` parse the new shape and `adminHref({ type: "globals" })` exists. `EnvironmentBadge` is removed.

**Live preview.** Nested-frame guard stops the admin recursing inside its own preview iframe; below the breakpoint the panel auto-closes and reopens as a bottom sheet (`LivePreviewMobileOverlay`, `LivePreviewToggleAction`) instead of taking over the page.

**Dark-mode focus rings.** `--shadow-*-val: none` invalidated the composed `box-shadow`, hiding focus rings; it is now `0 0 #0000` in `apps/test`, `apps/www`, and both create-vexcms templates (`base-nextjs`, `marketing-site` globals.css mirrored by hand; no other template sync needed for this change).

**Dogfood, docs, bookkeeping.** apps/test contributes `CachePurgeNote`, `CopyDocumentIdMenuItem`, `EditorialChecklist`, `SaveWithAnalytics`; guides `admin-customization`, `framework-adapters`, `live-preview`, and `dev/package-layout` document the new surfaces. Six changesets (all `patch` per the alpha track). Spec H ticked 41/41; launch plan, list-view spec I, state, tasks, and session logs updated.

**Polish.** Moved the unsaved-changes guard into `documents/` (clears a `react-app-form` struct violation); extracted a shared `versions/showsUnpublish` predicate for the Publish/Unpublish built-ins; replaced `CollectionDuplicateMenuItem`'s `saved as VexDocument` cast with a properly `undefined`-typed `document` prop and a runtime guard in `useDuplicateCollectionDocument`; documented (JSDoc + `admin-customization.mdx`) that `edit.actionsMenu` items must gate visibility via `access`, not a render-time `null`, and moved `RevalidateMenuItem`'s kind check onto its `access` predicate; added a `SlotOverrideOutlet` re-render test for a cleared override error; added `@types/react` to `@vexcms/core` so `pnpm check:vercel` resolves core's build.

BREAKING CHANGE: collection admin routes moved from `/admin/<slug>` to `/admin/collections/<slug>` with no redirect — update bookmarks and hard-coded links (use `adminHref`). `DraftToolbar` is removed from `@vexcms/react`; customize the edit header through `admin.components.edit` slots and `BUILTIN_CONTRIBUTION_IDS.edit` instead.
