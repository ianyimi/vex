refactor(core,react)!: make core react-free, move client wrappers to @vexcms/react/client

**Client wrappers move to `@vexcms/react/client`.** The tanstack/convex-react-query wrappers
(`get`, `find`, `search`, `create`, `update`, `remove`, `getGlobal`, `findGlobals`,
`updateGlobal`, `saveDraft`, `publish`, `unpublish`, `listVersions`, `getVersionSnapshot`,
`deleteVersion`, `findQueryKey`) and `VexQueryOptions` leave core for a new `./client` subpath
on `@vexcms/react`. They stay out of the `@vexcms/react` barrel so `NextAdminPage` (RSC) never
pulls `@convex-dev/react-query`. Core's root now exports `GetGlobalReturn` and
`VersionSnapshotResult`, which the moved code needs.

**Core has no React dependencies.** Peers drop to `convex` only; `react`, `lucide-react`,
`@tanstack/react-query`, `@tanstack/react-table`, and `@convex-dev/react-query` are removed from
peers and dev deps, and core's tsconfig extends `base.json` instead of `react-library.json`.
The built `dist` imports only `convex/*`, `zod`, `nanoid`, and `pluralize-esm` — a fresh
`npm i @vexcms/core` stops pulling ~70 MB of React packages.

**Icon names come from codegen.** `LucideIconName` becomes the library-neutral `IconName`,
resolved from `GeneratedVexTypes["IconName"]` (`string` before generate). `vex generate` now
emits `IconName: keyof typeof import("lucide-react").icons`, keeping the same autocomplete and
leaving room for other icon sets. `apps/test` regenerated; both create-vexcms templates'
`vex.types.ts` patched to match.

**Cell props stay in core.** `CellComponentProps.row` is the structural `CellRow<TData>`
(`{ original: TData }`) instead of React Table's `Row`, which still satisfies it.

**Docs.** `guides/globals.mdx` imports from `@vexcms/react/client`; `fields/blocks.mdx` and the
blocks JSDoc use canonical PascalCase icon names (the lowercase examples would now fail to
type-check) and document `IconName`. Changeset `core-framework-agnostic.md`.

BREAKING CHANGE: `@vexcms/core/client` is removed — import the same names from
`@vexcms/react/client`. `LucideIconName` is renamed `IconName`; re-run `vex generate` for
icon autocomplete. `CellComponentProps.row` only guarantees `row.original`.
