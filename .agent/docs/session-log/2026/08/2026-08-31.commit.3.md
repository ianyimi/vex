chore(release): harden the release pipeline for the first alpha

Implements WP-1 of the launch-readiness plan: everything that must be true
before the first alpha publish (WP-5) and the rebuild→master promotion (WP-B,
whose push triggers release.yml).

**Prerelease mode + docs privatization.** `apps/docs` is now `private: true`
and changeset-ignored — it would otherwise publish to npm as `docs`. Entered
changesets pre mode (`.changeset/pre.json`, tag `alpha`); a version rehearsal
confirmed the whole fixed group lands on `0.1.0-alpha.2`, with `docs` and
`www` untouched.

**Peer-cascade fix.** With no major changeset on disk, `changeset version`
still produced `1.0.0-alpha.2`: changesets escalates any peer-dependent to
major on any peer bump, and the fixed group propagated it to all 8 packages.
Setting
`___experimentalUnsafeOptions_WILL_CHANGE_IN_PATCH.onlyUpdatePeerDependentsWhenOutOfRange: true`
gates the cascade on an actual range exit. See ADR-007.

**Publish through pnpm.** The root `release` script now runs
`pnpm publish -r --no-git-checks --tag alpha && changeset tag` instead of
`changeset publish`, which shells out to npm and leaks unresolved `catalog:`
specifiers into published manifests. All 8 publishable manifests set
`publishConfig.tag: "alpha"` so `latest` stays on 0.0.19 until promotion.
`release.yml` gains a `Check Packed Manifests` step running
`scripts/check-packed-manifests.mjs` before the changesets action; the gate
was negative-tested (a broken manifest makes it exit 1).

**Apache-2.0 licensing + npm metadata.** Adds the canonical `LICENSE`
(apache.org text, checksum-verified) and `NOTICE` (Isaiah Anyimi). All 8
publishable manifests now carry `license`, `description`, `keywords`,
`author`, `homepage`, and `repository` with per-package `directory`;
`sideEffects: false` where verified, `["*.css"]` for `@vexcms/next` (exports
`./styles`). `roadmap.md`'s stale "MIT core forever" now reads Apache-2.0,
matching the README. A patch changeset covers the manifest changes.

**Harness bookkeeping.** New spec `2026-08-31-wp1-release-integrity` (3 task
groups, 13/13 steps verified), ADR-007, session log, ledger, state/tasks.
